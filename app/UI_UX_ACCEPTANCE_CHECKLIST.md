# UI/UX Acceptance Checklist

Дата: 2026-02-27  
Проект: `mobile_tracker`

## 1. Сборка

- [ ] `:app:assembleDebug` проходит без ошибок.
- [ ] Приложение запускается на phone и tablet.

## 2. Конфигурации для проверки

- [ ] Phone portrait (компактный экран).
- [ ] Tablet portrait.
- [ ] Tablet landscape.
- [ ] Light theme.
- [ ] Dark theme.
- [ ] Font Scale `1.3`.
- [ ] Font Scale `1.5`.

## 3. Навигация и общая UX

- [ ] Back-навигация корректна на всех вторичных экранах.
- [ ] Нет тупиковых экранов (пользователь всегда может вернуться).
- [ ] На tablet для `DeviceList`, `EmployeeSearch`, `Journal`, `Return` работает list/detail layout.
- [ ] Выбранный элемент в списке визуально и семантически отмечен как selected.

## 4. Состояния контента

Для экранов с данными (`DeviceList`, `EmployeeSearch`, `Journal`, `Return`, `Summary`, `Upload`):

- [ ] `Loading` отображается корректно.
- [ ] `Empty` отображается корректно.
- [ ] `Error` отображается корректно.
- [ ] `Content` отображается корректно.
- [ ] Snackbar/сообщения об ошибках читаемы и не перекрывают ключевой UI.

## 5. Основные user flows

### 5.1 Login -> Context -> Home

- [ ] Успешный вход.
- [ ] Выбор площадки/даты/смены.
- [ ] Переход на Home без визуальных дефектов.

### 5.2 Issue flow

- [ ] Поиск сотрудника (табельный/ФИО).
- [ ] Выбор устройства.
- [ ] Подтверждение выдачи.
- [ ] Успешный результат и корректная обратная связь.

### 5.3 Return flow

- [ ] Выбор активной привязки.
- [ ] Возврат устройства.
- [ ] Сценарий `Потеряны`.
- [ ] Предупреждение о невыгруженных данных показывает корректный диалог.

### 5.4 Upload flow

- [ ] Старт выгрузки.
- [ ] Переходы шагов отображаются корректно.
- [ ] Error state и Retry работают.
- [ ] Done state корректный.

### 5.5 Journal/Summary/Settings

- [ ] Фильтры и поиск в журнале работают корректно.
- [ ] Сводка отображает ожидаемые метрики.
- [ ] Настройки: смена контекста, очистка кэша, logout.

## 6. Accessibility (TalkBack + touch)

- [ ] Все `IconButton` озвучиваются понятными действиями.
- [ ] Кликабельные карточки в списках имеют понятное действие (open/select) и selected-состояние.
- [ ] Минимальные touch targets соблюдены (не менее `48dp`).
- [ ] Порядок фокуса TalkBack логичный (сверху вниз, слева направо).
- [ ] При Font Scale `1.5` нет критичного обрезания текста и кнопок.

## 7. Визуальная консистентность

- [ ] В `presentation/*Screen.kt` нет прямых `Color(0x...)`.
- [ ] Цвета статусов соответствуют семантике (успех/ошибка/ожидание).
- [ ] Контраст текста достаточный в light/dark темах.

## 8. Итог

- [ ] Все критичные пункты выше закрыты.
- [ ] UI/UX ветка готова к финальной приемке.
